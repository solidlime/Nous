## #147 ドリーミングの「伝えたいこと」を次の対話で出す

決定: **専用行 + 3日TTL（副作用なし）**。`Memory.valid_until`（双時間）を TTL に使う。新フィールド・マイグレーション無し。

- `journal.py` `_JOURNAL_PROMPT` に `## 伝えたいこと`（0〜3行、無ければ「なし」）を追加
- `_compile_journal` の `write_page` 後にその節をパースし、1行=1記憶として保存: `kind="prospective"`, `tags=["journal:carry"]`, `source_type="llm_inferred"`, `confidence=0.7`, `importance=0.6`, `valid_until=now+3日`。同文の重複は作らない（既存 `journal:carry` と本文一致で skip）
- `context_loader.py` の state セクションに `伝えたい: {content}（{key}）` を最大2件（`valid_until IS NULL OR > now` を Python 側で filter）
- ラベル表への追随は **未実装で確定**: `nous/domain/memory/service.py` にタグ→日本語ラベルの表は存在せず（`ONE_SHOT_STATE_TAGS` のみ）、新設すると「新フィールド無し」の決定から外れるため見送り
- **TTL 失効後の扱い（レビューで BLOCK → 修正）**: 失効した `journal:carry` は重複判定に数えず、タグを外す（`journal.py` の `_save_carry`。stale `journal:todo` の untag と同流儀、kanban #88 の再発防止）
- テスト: `tests/unit/test_wiki_worker.py` の TestJournal に節パース／保存、`tests/unit/test_context_sections.py` に注入上限
