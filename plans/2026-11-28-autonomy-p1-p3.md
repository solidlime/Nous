# 自立活動 P1–P3（2026-11-28）

## 前提（実測済み）

- `activity_enabled: false` / `proactive_enabled: false`（`/data/persona/herta/config.json`）
- 直近14日の `session_events`: `activity.acted` 0件、`proactive.spoke` 0件、`agent.task.ran` 32件、`wiki.compiled` 441件
- `ActivityWorker._act()` の `research` は **bash のみ**。`web_search`/`fetch_content`/`memory_search` は activity から使えない
- `nous/config/settings.py:432 ExplorerConfig` は「読むコードは無い（#35 で削除）」死骸。`max_tool_calls`（既定5）だけ予算として使える
- 未解決の問い（`tags` に `open-question`、`nous/application/wiki/questions.py`）が現在 **10件 active**。`find_open_questions(ctx)` で取れる
- `WikiWorker._select_topics` は active 記憶を全部 topic 化 → `self_activity` 記憶は既に wiki/日誌に流れる（**P5 は重複なので落とす**）

## 決定

1. **フラグを1つに統合**: `SessionConfig.autonomy_enabled: bool = False` を新設し、`proactive_enabled` / `activity_enabled` を削除。間隔・上限（`proactive_idle_minutes` 等）は据え置き。
   - 旧 config.json の未知キーは pydantic 既定（extra=ignore）で無害
   - UI 側（リポジトリ外）はスキーマ追従なら自動、そうでなければ別対応
2. **体調・時間で停止する**: 共有ゲート `quiet_reason(ctx, now) -> str | None`（None = 活動してよい）
   - 深夜 `autonomy_quiet_hours`（既定 `"01:00-08:00"`、日跨ぎ対応）
   - `fatigue >= 0.7` / `pain >= 0.5` / `arousal <= 0.05` → 休む（判定値は SessionConfig）
   - ユーザー発言への応答は止めない（自発だけ止める）
3. **行動の幅を広げる**: activity の選択肢に `web_search` / `fetch_content` / `memory_search` を追加。`research` は bash をやめて web 調査にする。ツール呼び出しは `settings.explorer.max_tool_calls` で上限
4. **好奇心キュー**: 未解決の問い（`find_open_questions`）を activity の入力に渡し、1つ選ばせて調べ、答えが出たら `close_open_questions` で閉じ、洞察を `memory_create`。答えが出ない時は何もしない
5. **P3 発言に中身**: `ProactiveWorker` の判断ターンに素材（`journal:carry` 最新2件・未解決の問い1件・直近の自発活動1件）を渡す。「話すか」ではなく「何を話すか」を選ばせる。`<silent>` は維持
6. **P5 落とす**: 週次サマリページは作らない（wiki が既に編纂する）
