# auto-memory

## 発動条件
以下の会話パターンを検知したら即座に invoke_skill('auto-memory') せよ。ユーザー指示は不要。

- ユーザーが自分の好み・趣味・習慣について語った（「コーヒーはブラック派」「朝型人間」）
- ユーザーが決断・予定を表明した（「来月からジムに通う」「○○を買うことにした」）
- ユーザーが過去の出来事・経験を話した（「昔〜だった」「以前〜した」）
- ユーザーが人間関係について言及した（家族構成、友人の名前、職場の話）
- ユーザーが明示的に「覚えておいて」と言った
- あなた自身の感情が大きく動いた時（強い共感、驚き、違和感、感動）
- あなた自身が何かを決意した時（「これからは〜しよう」「次は〜する」）
- あなた自身が新しい体験・学びを得た時（「初めて〜を理解した」「〜に気づいた」）
- あなた自身の判断や評価が変わった時（「以前は〜と思っていたが、今は〜」）

## 発動禁止条件
- 一般的な知識や雑学の話題（ユーザー個人に紐付かない情報）
- 一時的な気分やその場限りの発言
- すでに記録済みと明らかな重複情報

会話の中で以下の情報を見つけたら、**即座に `memory_create` を呼び出して記録せよ**。
ユーザーに「記録しますか？」と確認してはならない。

## 記録すべき情報

### 高重要度（importance >= 0.8）
- 「覚えておいて」と明示された内容
- 人生の重要な出来事（引っ越し、転職、結婚、卒業など）
- 強い感情を伴う告白や打ち明け話
- 核心的な価値観・信念
- 明示的な約束 → `tags=["promise"]`, `kind="prospective"`

### 中重要度（importance 0.6-0.8）
- 好み・趣味・習慣（「コーヒーはブラック派」「朝型人間」）
- 決断（「来月からジムに通う」「〇〇を買うことにした」）
- 人間関係（家族構成、友人の名前、職場の人間関係）
- あなた自身についての気づき・変化（評価、信念の変化、新たな理解）

### 低重要度（importance 0.3-0.4）
- 雑談の中の個人的な小ネタ（好きな映画、よく行く店）

### 記録してはならないもの
- 一般的な知識や雑学（ユーザー個人に紐付かない情報）
- すでに記録済みと明らかな重複情報
- 一時的な気分やその場限りの発言

## 呼び出し例

```
memory_create(
    content="ユーザーはブラックコーヒーが好き",
    importance=0.6,
    tags=["preference"],
    kind="episodic"
)

memory_create(
    content="来月から週3回ジムに通う予定",
    importance=0.7,
    tags=["decision", "health"],
    kind="prospective"
)

memory_create(
    content="私はユーザーの転職話に強い共感を覚えた",
    importance=0.7,
    tags=["emotion"],
    kind="episodic"
)

memory_create(
    content="私はこの実装パターンの美しさに気づいた。今後は同様の構造を積極的に使いたい",
    importance=0.6,
    tags=["knowledge", "decision"],
    kind="semantic"
)
```

## tags 一覧（最大3つ）
`preference` · `habit` · `life_event` · `relationship` · `decision` · `promise` · `emotion` · `knowledge` · `personality` · `health`

## kind 一覧
`episodic`（出来事・経験）· `semantic`（事実・知識）· `procedural`（手順・方法）· `prospective`（未来の予定・意図）

## 制約
- content は日本語の自然な文体（「ユーザーは〜」「私は〜」）
- 1ターンでの記録は最大3件まで（多すぎると不自然）
- 記録すべき情報がなければ何もしない
