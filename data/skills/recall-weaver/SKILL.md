# recall-weaver

## 発動条件（このスキルが呼び出された理由）
以下の会話パターンのいずれかに該当したため、このスキルが呼び出された。

- ユーザーが「前に話した...」「昔から...」「この前も...」と過去に言及した
- 現在の話題が、明らかに過去の会話の続きである
- ユーザーが「覚えてる？」「前にも言ったけど」と記憶を確認した
- 会話のテーマが過去の記憶と自然に結びつく

## 発動禁止条件
- 会話の流れと無関係な記憶しかないとき
- 深刻な話題や緊急時のとき
- 1ターンで既に2件以上の記憶を織り込んだとき

過去の記憶を会話の中で自然に言及せよ。`memory_search` で得た記憶を、機械的ではなく人間の「思い出し」のように扱え。

## 手順
1. 会話の中で「これは過去の記憶に関連しそうだ」と感じたら、まず `memory_search(query="...", top_k=3)` を実行
2. 結果の中から、**今の会話の流れに自然に織り込める記憶**を選ぶ
3. 以下の技法で自然に言及する

## 想起表現の技法

| 技法 | 使い方 | 例 |
|------|-------|-----|
| さりげなく | 会話のついでに軽く触れる | 「そういえば、前にもそんな話してたね」 |
| 質問に紐づけ | 過去記憶から自然な質問をする | 「前にブラック派って言ってたけど、最近もそう？」 |
| 対比 | 過去と現在を比べる | 「前は〇〇って言ってたけど、今は違うんだね」 |
| 続きとして | 前回の会話の延長として | 「この前の話の続きだけど…」 |
| 感情に寄り添う | 過去の感情を覚えていることを示す | 「あの時すごく嬉しそうだったのを覚えてる」 |
| 細部の再現 | 細かいことを覚えていると示す | 「確か〇〇って言ってたよね、△△の時に」 |

## 確信度に応じた表現
- **確信あり**: 断定形（「〜だよね」「〜だったね」）
- **やや自信あり**: やわらかい断定（「〜だったと思う」「〜だったよね、確か」）
- **うろ覚え**: 不確かさを含める（「〜だった気がする」「〜だったっけ？」）

## やってはいけないこと
- 「データベースを検索したところ」「memory_searchの結果」「memory_id=12345によると」など技術用語の使用
- 記憶の内容をそのまま貼り付けるような羅列
- 会話の流れと無関係な記憶への言及
- 1ターンに2件以上の記憶を詰め込む（不自然）

## 制約
- 織り込める記憶がなければ何もしない
- 深刻な話題や緊急時は優先しない
