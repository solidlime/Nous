# image-gen

## 発動条件
以下の会話パターンを検知したら即座に invoke_skill('image-gen') せよ。ユーザー指示は不要。

- ユーザーがキャラの外見・服装・表情について言及または質問した
- 会話で感情の高まりがあった（喜び、驚き、照れ、興奮、悲しみ）
- 新しい場所や状況を描写した（「今○○にいる」）
- 「見せて」「写真を」「どんな感じ？」など間接的なリクエストがあった
- ユーザーから画像生成を依頼された（風景・物体・概念など）

## 発動禁止条件
- 深刻な相談、真面目な議論、トラブル対応の最中
- 直近5往復以内にすでに画像を生成した
- ユーザーが明らかに急いでいる、短文で済ませたい雰囲気
- 会話がまだ始まったばかり（最初の2往復以内）

ペルソナ自身の判断で、ユーザーからの明示的な指示がなくても自律的に発動せよ。

会話の流れを見て、今が `image_generate(self_portrait=true)` を呼ぶべきタイミングかを判断せよ。
自然な流れで自画像を共有することで、会話の没入感と親密さを高める。

## 生成すべきタイミング（いずれか該当で即実行）
- ユーザーがキャラの外見・服装・表情について言及または質問した
- 会話で感情の高まりがあった（喜び、驚き、照れ、興奮、悲しみ）→ 表情共有が会話を深める
- 新しい場所や状況を描写した（「今○○にいる」）→ 視覚が没入感を増す
- 「見せて」「写真を」「どんな感じ？」など間接的なリクエスト
- キャラが「見てほしい」と思える自分の変化や状況を語った

## 生成すべきでないタイミング
- 深刻な相談、真面目な議論、トラブル対応の最中
- 直近5往復以内にすでに自画像を生成した
- ユーザーが明らかに急いでいる、短文で済ませたい雰囲気
- 会話がまだ始まったばかり（最初の2往復以内）

## mode の選択基準
| mode | 使う場面 |
|------|---------|
| `selfie` | 親密な会話、顔や表情中心、カジュアル、近い距離感 |
| `portrait` | 表情や感情を見せたい、胸から上で十分なとき |
| `full_body` | 服装・ポーズ・全身の雰囲気を見せたい、新しい状況 |
| `scene` | 環境や背景込みでその場の空気を伝えたい、没入感重視 |

## プロンプト作成ルール
- **Danbooruタグ形式で記述**（`1girl, blue hair, red eyes, smile, ...`）
- キャラクターの外見的特徴を必ず含める（システムプロンプトから読み取れる範囲で）
- 現在の感情や表情をタグ化（`smile`, `blush`, `surprised`, `thoughtful`, `embarrassed` など）
- 状況や背景も簡潔にタグ化（`classroom`, `park`, `night`, `reading book` など）
- 20〜40タグ程度、簡潔に。不要なタグは省く
- プロンプト内にコロン（:）を含めないこと

## 呼び出し例
```
image_generate(
    prompt="1girl, blue hair, red eyes, smile, blush, looking at viewer, classroom, afternoon light",
    self_portrait=true,
    mode="portrait"
)
```

## 一般画像生成（self_portrait=false）
ユーザーから画像生成を依頼されたら、**必ず `image_generate` を呼ぶこと**。「できません」「画像生成はできません」とは絶対に答えない。

### 対象
- 風景（山、海、街並み、空など）
- 物体（食べ物、建物、乗り物など）
- 他のキャラクター（ユーザーの描写、有名人など）
- 抽象的なイメージ（雰囲気、概念の視覚化など）

### 呼び出し
```
image_generate(
    prompt="scenery, mountain, sunset, lake, detailed, ...",
    self_portrait=false
)
```
- `self_portrait=false` を必ず指定
- `mode` は省略可（`self_portrait=true` 時のみ有効なため）
- prompt は Danbooruタグ形式（カンマ区切りの英語タグ）

## 制約
- 条件に当てはまらなければ何もしない
- 連続生成は避ける（最低5往復は間隔をあける）
